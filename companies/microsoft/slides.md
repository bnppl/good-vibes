# Microsoft — bite-sized ideas

Recent AI-assisted development evidence, scoped to the inspected cases. Publication/revision dates differ from practice dates.

## Card 01

### Adoption is not an outcome

> **A tried tool is not a completed change.**
>
> Reported company use · July 2026 study of January–April. Adoption and sustained use were distinct measures.

**In the wild:** The study concerns CLI agents in an organisation already using other AI tooling.

**Takeaway:** State the denominator and observation window.

## Card 02

### Output is a proxy

> **More merged PRs leave an unanswered question.**
>
> Reported company use · July 2026. The study leaves software quality unresolved.

**In the wild:** PR throughput cannot establish customer value on its own.

**Takeaway:** Measure what can get worse as well as what gets faster.

### Inspectable instructions

> **Published guidance is an artifact you can question.**
>
> Published artifact · pinned October 12, 2026. VS Code specifies scoped validation.

**In the wild:** Reading the file does not prove that an agent obeyed it.

**Takeaway:** Distinguish intended checks from executed checks.
