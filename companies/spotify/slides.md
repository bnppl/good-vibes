# Spotify — small ideas from reported practice

Window: 1 October 2025–26 October 2026. Each card names its evidence kind and date. [Detailed research](research.md) retains the scope and limits.

## Card 01

### The incomplete migration

> **A real success story can include work deliberately deferred.**
>
> Reported team use · published 2026-04-22. The dataset case did not force every framework through the same prompt.

**In the wild:** Migration initiated after late-2025 deprecation planning. A substantial case, not a completed migration of every targeted framework.

**Takeaway:** Make unsupported scope visible.

## Card 02

### Prompt preconditions

> **Tell the agent when the task does not apply.**
>
> Reported team use · published 2025-11-24. The context-engineering account recommends preconditions and bounded changes.

**In the wild:** Retrospective experiments and then-current migration practice. Task prompting advice is distinguished from reports of actual tool restrictions.

**Takeaway:** An explicit no-change result can protect a migration.

## Card 03

### Two kinds of checks

> **Passing CI and satisfying intent are different claims.**
>
> Reported team use · published 2025-12-09. Honk uses executable verifiers and a separate scope judge.

**In the wild:** Feedback-loop design before publication. A working check pipeline does not guarantee functional correctness or validated judge accuracy.

**Takeaway:** Evaluate each verification layer independently.
