## How these studies were prepared

Five parallel agents applied the same `/engineer` workflow, with one agent responsible for each person's directory. Existing Farley research was reused without an external refresh; the other four profiles were researched from primary material. Slide generation followed the cache stage. Read each source register for its evidence horizon and gaps.

The worked reward example in the research guides is a suggested adaptation, not an implementation attributed to the engineer. Public advocacy, demonstrations, reported personal practice, and our proposed applications remain separate.
