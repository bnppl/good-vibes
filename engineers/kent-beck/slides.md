## Card 04

### A swarm is a feature

> **More agents can create more work for the human steering them.**
>
> Personal use · published 2026-04-23. In an Intent session, Beck reported carrying coordination state himself. His question is whether the tool delivers the desired outcome. This is an account of one experience, not a universal benchmark.

**In the wild:** Reported project: Go adaptive radix tree, readability goal, Intent coordinator/implementer/verifier, and a human left tracking the coordination.

**Takeaway:** Optimise the outcome, not the agent count.
