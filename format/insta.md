### 📋 CORE FRAMEWORK: THE "INSTA-STYLE" EDUCATIONAL SLIDESHOW

When asked to generate an "Insta-style" slideshow or carousel for learning, strictly adhere to this visual storytelling framework. It is designed to maximize retention, maintain curiosity, and eliminate cognitive overload by rationing information across 6 to 8 highly visual steps.

#### PHASE 1: THE CURIOSITY GAP (Slide 1)
*   **The Hook:** Features a bold, highly intriguing, or contrarian technical headline.
*   **The Goal:** Stops the user from skipping ahead and creates an immediate desire to find the answer. It must promise a shortcut, a hidden truth, or a fix to a frustrating engineering problem (e.g., *"Why your RAG pipeline is lying to you"*).

#### PHASE 2: THE MICRO-DOSE BREAKDOWN (Slides 2–5)
*   **Rationed Information:** Each slide acts as a single, isolated thought. Max 25 words per slide.
*   **Progressive Disclosure:** Break complex concepts down chronologically. Slide 2 states the problem -> Slide 3 introduces the component -> Slide 4 shows the mechanism -> Slide 5 shows the final result.
*   **Visual Anchors:** Text must never stand alone. Use bolded keywords, short bullet fragments, minimal diagrams, or 3-line code blocks so the brain processes the structure instantly.

#### PHASE 3: THE SYNTHETIC CONSOLIDATION (Slide 6)
*   **The "Aha!" Moment:** Compress the entire lesson into a single, highly memorable mental model, comparison table, cheat sheet, or golden rule.
*   **The Purpose:** Rewards the user for navigating through and solidifies active recall.

#### PHASE 4: THE ACTIONABLE PROMPT (Slide 7/8)
*   **The Directive:** A single, explicit call-to-action tailored for learning. 
*   **The Purpose:** Replaces typical social media "Like/Share" metrics with an active learning prompt, such as: *"Now write this code block from memory"* or *"Explain this mechanism to a peer."*
